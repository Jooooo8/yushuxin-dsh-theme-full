## 二、已交付内容

- 插件包：`yushuxin-appearance/`，包名 `@local/yushuxin-appearance`
- 安装状态：已通过 `install_bundle` 安装到当前 profile，`application: applied`，无警告；Host 行 `include:yushuxin-appearance` 处于 `active`
- 重启实证：Harness 重启后（Web GUI 端口由 5806 变为 12925）复查 profile 配置与 Loader 列表，`@local/yushuxin-appearance` 与 `@local/qyu-companion` 仍为 `enabled: true / active`，link 目标 `C:\Users\LENOVO\Desktop\dsh插件\...` 完好 → 插件与内嵌素材均随 profile 持久化，无需重装
- 主题层：调用 Client `theme.overrideTokens()`，以 source `@local/yushuxin-appearance` 叠加浅色/深色 token，不修改内置主题
- 照片：`虞书欣/` 下全部 107 张，统一裁成 360×480 高清缩略图（JPEG q72，兼顾放大灯箱的清晰度），以 base64 data URI 内嵌在 `client.js`（约 3.76 MB）。胶片为深梅色底 + 每格上下齿孔；3 份拷贝实现无缝循环，rAF 以约 27px/s 自动右→左滑动；悬停/拖拽/灯箱打开时自动暂停。
- 音效：Web Audio API 振荡器现场合成（hover 嗒声 1700Hz、点击 760Hz、翻页 1300Hz），不依赖音频文件；AudioContext 在首次点击时创建/恢复，符合自动播放策略；静音偏好存 `localStorage` (`ysx-muted`)。
- 原始照片中 102 张实际是 JPEG 但扩展名为 `.png`，另有 PNG/GIF，已按文件内容识别并统一转成标准 `data:image/jpeg`；GIF 取首帧。
- 主界面专用素材：另从照片 005 / 090 裁出 120×120 圆形头像与 200×200 Hero 方图，共 **109 个**内嵌图片 URI，客户端模块约 3.79 MB。

## 三、查看与验证

1. 由于当前没有运行 `pnpm run dev:web` 监听，新客户端模块不会自动热更到已打开的页面，请**刷新 Web GUI 页面（F5）**。
2. 刷新后：界面呈玫瑰粉色调；输入框下方的胶片自动缓慢从右往左滑动，到头自动接续（无缝循环）。鼠标划过照片有「嗒」声和倾斜浮起放大；左键点击弹出放大灯箱并迸发粒子，灯箱内可左右切换、Esc 或点空白关闭；右上角 🔊 可静音。
3. 主界面其它位置：顶栏左侧有「小石榴」胶囊；会话标题右侧有虞书欣头像 + 跳动爱心；新建会话的 Hero 区有圆形虞书欣照片 + 石榴角标；全屏角落有柔光，石榴籽/星星/爱心缓缓飘落。
4. 光标停在胶片上只会**放慢**不会停；按住某张照片**往上拖**松手也能放大；音效比之前明显更响。
5. **版本确认**：胶片标题「小石榴」徽章右边有一个 `v2.0` 小字。看到它 = 新客户端模块已加载；看不到 = 页面还在用旧模块，请 Ctrl+F5，仍不行则重启一次 Harness（改完 `client.js` 后需要让 Host 重新扫描模块图，重装 bundle 也会触发）。
5. 浅色 / 深色模式均单独配色，可在「设置 → 外观」中切换验证。
6. 插件管理器中可见标题「虞书欣 · 欣动外观」及自制图标。

## 四、自定义

- 换照片：`虞书欣/` 里增删图片后重跑 `build_photos.py`（现在会自动收录文件夹内全部文件），生成的 `client.js` 因 link 安装即时生效，强制刷新页面即可，无需重装。
- 换配色：编辑 `client.template.js` 顶部的 `OVERRIDES` 对象（每个 token 都是 `{ light, dark }` 成对值），重跑 `build_photos.py` 生成 `client.js`。
- 卸载：插件管理器中移除 `@local/yushuxin-appearance` bundle；`overrideTokens` 的 disposer 会随插件卸载自动撤销主题层。

## 五、自我追问式头脑风暴

**问：自动滑动会不会打扰用户打字？**
答：悬停、拖拽、灯箱打开时都会暂停；速度压到约 27px/s（3 秒才走一格），只是余光里的呼吸感。下一轮可加一个 ⏸/▶ 显式开关。

**问：循环 107 张，怎么找特定的一张？**
答：现在有 `n / 107` 计数 + 当前格高亮；下一轮可以加「跳转到第 N 张」输入框、双击收藏（收藏夹存在 localStorage）、或按拍摄日期分组成分卷。

**问：hover 音效会不会吵？**
答：嗒声只有 50ms、音量 0.05、60ms 节流，且默认首次点击后才启用；头部有 🔊 一键静音并记忆。下一轮可以换成真正的「胶片过片」机械声采样。

**问：107 张高清图会不会卡？**
答：单张压到 360×480 q72（约 35KB），全部内嵌约 3.76MB；计数器只在跨格时才触发 React 重渲染，粒子 1.6 秒自动回收。下一轮可用 IntersectionObserver 只渲染可视格 + 两侧缓冲。

**问：小石榴元素会不会太杂？**
答：统一收在八处——胶片标题徽章、胶片两端石榴摆件、灯箱字幕胶囊、点击粒子里的石榴籽、顶栏「小石榴」胶囊、Hero 石榴角标、全局飘落的石榴籽、会话头部玫红头像描边；颜色固定 `#d94f70 / #e86b8c` 玫红系，不和照片争艳，且全局氛围层 `pointer-events:none` 不挡任何操作。下一轮可在每轮对话完成时掉一颗小石榴作为「应援奖励」。

**问：还能怎么宠粉？**
答：候选点子——①「今日欣运」每天随机抽一张做封面；②灯箱里加一句该照片的应援文案；③键盘 ←/→ 在胶卷上也能用（不只灯箱）；④和 Q 版欣宝联动：点欣宝时她举起当前那张照片；⑤生日/纪念日当天胶卷变限定皮肤。
